# Посещаемость PWA v2

Вторая версия: локальное хранение через IndexedDB (асинхронная БД браузера), без серверов и облака.

## Файлы
- `index.html` — оболочка
- `app.js` — UI и IndexedDB
- `style.css` — оформление
- `sw.js` — кеширование оболочки для офлайн запуска
- `manifest.webmanifest` — PWA манифест
- `icon.svg` — иконка

## Установка через GitHub Pages
1. Создать репозиторий GitHub.
2. Загрузить содержимое папки `attendance_pwa_v2` в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. После публикации открыть URL Pages на iPhone через Safari → Поделиться → На экран «Домой».

## Локальные данные
IndexedDB хранит настройки группы, студентов, названия пар и отметки. Данные не отправляются на сервер и не синхронизируются между устройствами. Регулярно экспортируйте JSON резервную копию.

## Текущие ограничения v2
Учет отмечает посещаемость по дням, не по каждой отдельной паре. Названия пар можно хранить как список, но сетка пар/окон пока не реализована. Статистика — месячная и до выбранной даты; CSV экспортируется как Excel-совместимый файл. Для настоящего XLSX понадобится отдельная библиотека, которую в данной версии не подключаем (приложение остается полностью офлайн).
